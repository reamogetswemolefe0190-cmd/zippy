VARIANT 01 Kinetic Pulse

The Kinetic Pulse

A bold geometric lettermark fused with a high-velocity 45° lightning conduit. Features rounded terminals and an energetic trailing spark dot representing instant cash confirmation.

Pattern: Line System + Spark
VARIANT 02 Bilateral Ribbon

The Bilateral Split

Two interlocking rounded capsule ribbons representing sender and receiver in perfect balance. Seamlessly communicates both merchant payments and social bill splitting between friends.

Pattern: Dual Ribbon Mesh
VARIANT 03 Modular Till Matrix

The Countertop Till

A 3x3 rounded squircle matrix inspired by physical point-of-sale keypads. Selective subtractions craft an architectural 'Z', evoking the four-digit countertop till code.

Pattern: Dot Matrix / Modular
VARIANT 04 Möbius Ribbon

The Infinite Flow

A single continuous closed path derived from the infinity loop, twisting through a central emerald void into a stylized letter Z. Symbolizes unceasing financial liquidity and effortless circulation.

Pattern: Continuous Void Loop
VARIANT 05 Radial Lightning

The Staggered Beam

Rhythmic parallel vector rays with staggered lengths and precise 12px gaps. Harnesses visual tension through asymmetry, capturing the rapid pulse of South Africa's PayShap network.

Pattern: Asymmetric Ray System
VARIANT 06 Negative Cut Monolith

The Kasi Monolith

A solid dark squircle badge housing a sharply carved lightning monogram. Formatted specifically as an ultra-high-definition iOS/Android home screen icon and browser favicon.

Pattern: App Icon / Cutout
